## Entorno de desarrollo

- Python 3.12
- GitHub Codespaces, con la configuración en `.devcontainer/devcontainer.json`

Para abrir el entorno: botón **Code** > pestaña **Codespaces** > **Create codespace on main**.

## Seguridad

Las claves API se guardan en archivos `.env`, que están excluidos en `.gitignore` y nunca se publican. Cada entrega incluye un `.env.example` con los nombres de las variables necesarias, sin valores reales.
